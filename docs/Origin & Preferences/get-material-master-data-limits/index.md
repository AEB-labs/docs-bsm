There are two option how to consume the material master data. 

* get a single record by materialNumber, destinationCountry etc.
* get all changed material master data

If you like to persist the data in your system it is better get all changed master datas. But if you just like to request one material master data for perhaps an transaction then it is ok to use the single request.
